# 使用 AI Agent

ComfyUI 插件不再提供内置 Agent 聊天、API 配置或模型请求接口。编辑器右下角提供可收起、展开的引导卡片，收起后保留入口，也可以从顶部“使用 AI Agent”切换。

仓库：https://github.com/topviewai/topview-3d-builder

将以下指令复制给 Qoder、Claude Code、Cursor 或其他支持 Skills 的 Agent：

```text
Install the Topview 3D Builder plugin from https://github.com/topviewai/topview-3d-builder for the agent I'm using (Qoder, Claude Code, Cursor or another agent with skills support). Follow the install steps in the README, then tell me when to restart.
```

场景编辑、保存、图片和视频导出照常使用。旧工作流中的历史数据和机器上已保存的配置不会在此次更新中自动删除。
